# IDO - Wedding

<p align="center"> <img src="https://img.shields.io/badge/Swift-6-orange" /> <img src="https://img.shields.io/badge/SwiftUI-Built%20With-blue" /> <img src="https://img.shields.io/badge/Firebase-Integrated-yellow" /> <img src="https://img.shields.io/badge/iOS-17+-important" /> </p>

iOS application to simplify wedding planning by organizing tasks, vendors, and notes into a beautiful and user-friendly layout. Built with Swift, SwiftUI, and Firebase, IDO streamlines the entire wedding preparation process. 


![image alt](https://github.com/gzorakes/IDO/blob/efed6e35f05ad6bb6dae6760aca6c98e0d8d05a4/Group%201.png)

## ✨ Features

- Create personalized wedding profiles (bride/groom, name, date)
- Organized planning categories (Event Hall, Invitations, Flowers, Dress, Guests, etc.)
- Attach images to each planning section
- Sign in with Apple for secure authentication and data backup
- Progress tracking, vendor comparison, and important information storage
- Elegant and joyful user interface with seamless UX

## 🛠️ Tech Stack

- Language: `Swift`, `SwiftUI`
- Architecture: Modular `MVVM`
- Concurrency: Swift `Concurrency`
- Local Storage: `SwiftData`, `UserDefaults`
- Backend: `Firebase`
- Dependency Management: Swift Packages
- Testing: `Unit Tests`, `UI Tests`
- CI/CD: `Xcode Cloud`

## 🏗️ Development Highlights

- `Protocol-oriented programming` and `dependency injection` for clear separation of concerns
- Swift Packages for feature-specific logic isolation
- `Custom build schemes`, targets, and environments for streamlined workflows
- Automated `CI` through Xcode Cloud for code quality maintenance

Make sure to configure your Firebase project and update any necessary API keys or the GoogleService-Info.plist file before running the app.
